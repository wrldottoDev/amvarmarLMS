# Cómo cambio las columnas que veo en el listado de cargas

<!-- palabras_clave: columnas, cambiar columnas, ocultar columnas, personalizar listado, ver mas datos -->

En **Cargas**, el botón **Columnas** abre un selector donde podés elegir cuáles mostrar: identificador
(WR o factura), empresa, número de factura, estado, shipper, carrier, CFTS, tracking, PO, contenedor,
peso, bultos, pendientes y fecha. El identificador y el estado siempre se muestran — no se pueden quitar
porque el listado dejaría de servir para identificar una carga.

La preferencia queda guardada para tu usuario: la próxima vez que entrés, ves las mismas columnas que
dejaste elegidas.
